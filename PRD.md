# 1. Product Overview

## Product Name

**A KID'S GUIDE TO CHANGE THE W🌎RLD – Official Website**

---

## Product Type

Single-page responsive promotional website (Landing Page)

---

## Primary Purpose

The website serves as the official online presence for the book.

It is intended to:

- introduce visitors to the book
- inspire children and parents
- encourage purchases
- establish credibility
- showcase the mission behind the book
- become the central hub for future educational resources

Although the initial version is a landing page, the design should be scalable enough to support future additions such as:

- activity downloads
- lesson plans
- companion resources
- school partnerships
- book series
- games
- AI experiences
- newsletters
- community programs

without requiring a redesign.

# 2. Vision Statement

The website should make visitors feel the same sense of wonder they experience when looking at the book cover.

It should communicate one central idea:

> **Every great innovation begins with curiosity.**

The experience should encourage children to believe they can shape the future while assuring parents and educators that the book is educational, inspiring, and trustworthy.

Rather than functioning as a standard online bookstore page, the website should feel like stepping into the world of the book itself.

# 11. Color Usage Rules

Gold should dominate.

White should provide breathing room.

Red should command attention.

Blue should appear sparingly.

Cyan should be reserved almost exclusively for holographic effects and interactive elements to preserve its sense of novelty.

Avoid introducing additional saturated colors that compete with the established palette.

### Accessibility and Contrast Rules

- All body text on gold backgrounds must use **Rich Navy (#10233E)**.
- White is reserved for cards, buttons, and elevated surfaces—not directly on gold backgrounds.
- If white text must appear, place it on a dark overlay or gradient that meets WCAG contrast requirements.

# 22. Website Information Architecture

The website should follow a storytelling structure rather than a traditional marketing funnel.

Instead of immediately trying to sell the book, the website should first inspire visitors, introduce the mission, demonstrate the value of the book, establish credibility, and then invite them to take action.

The narrative flow should feel like a journey:

```text

    ↓
Curiosity
    ↓
Purpose
    ↓
Discovery
    ↓
Connection
    ↓

    ↓
Action
```

This emotional progression should be reflected in the ordering of every section.

# Part 3 — Interaction Design, Motion System, Responsive Experience & Technical UX Specifications

---

# 44. Interaction Design Philosophy

The website should feel **alive**, but never distracting.

Interactions should reinforce one central idea:

> **Ideas grow into reality.**

Every hover, animation, transition, and movement should support this narrative.

If an animation does not strengthen the storytelling, improve usability, or provide meaningful feedback, it should not be included.

The desired emotional response is:

- Curious
- Inspired
- Confident
- Hopeful
- Engaged

rather than:

- Overstimulated
- Distracted
- Confused

---

# 45. Motion Design Principles

Motion throughout the website should follow five principles.

## Principle 1 — Purpose

Every animation should communicate something.

Examples:

- reveal information
- indicate interaction
- direct attention
- reinforce hierarchy
- express imagination

---

## Principle 2 — Restraint

Motion should remain subtle.

Nothing should bounce repeatedly or demand constant attention.

Avoid:

- spinning objects
- flashing effects
- exaggerated scaling
- rapid movement

---

## Principle 3 — Consistency

Animation timing should remain consistent across the website.

Recommended durations:

| Action | Duration | Design Token |
|---------|----------|--------------|
| Hover | 180ms | `--duration-fast` |
| Fade / Transition | 300ms | `--duration-medium` |
| Entrance / Scroll Reveal | 600ms | `--duration-slow` |
| Hero Animation | 2.5 seconds | `--duration-hero` |

---

## Principle 4 — Natural Movement

Objects should move using smooth easing.

Preferred easing:

```
ease-out
```

or

```
cubic-bezier(.22,.61,.36,1)
```

Movement should feel effortless.

---

## Principle 5 — Performance

Animations should rely on GPU-accelerated properties whenever possible.

Preferred properties:

- transform
- opacity

Avoid animating:

- width
- height
- top
- left

unless absolutely necessary.

---

Lucide React

- lightweight
- consistent outline style

- excellent accessibility

- useState
- useEffect
- useRef
- Context API (only if needed)
